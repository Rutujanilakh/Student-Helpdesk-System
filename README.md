
# Student Helpdesk System

## Project Description
The Student Helpdesk System is a Java-based console application that allows students to create, update, search, track, and resolve support tickets.

## Technologies Used
- Java
- JDK 17
- VS Code
- ArrayList
- Object-Oriented Programming (OOP)

## Features
- Create support tickets
- View all tickets
- Search tickets using Ticket ID
- Update ticket details
- Update ticket status
- Validate ticket category and priority
- Prevent empty ticket details
- Track ticket status: Open, In Progress, and Resolved

## Project Files
- Main.java – Main menu and user interaction
- Ticket.java – Ticket details and operations
- TicketManager.java – Ticket management
- User.java – User details

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile using `javac *.java`.
4. Run using `java Main`.

Beginner Java Project
