# Student Helpdesk System

## Project Description
The Student Helpdesk System is a Java-based console application that allows students to create, update, search, track, and resolve support tickets.

## Technologies Used
- Java
- JDK 17
- VS Code
- ArrayList
- Object-Oriented Programming (OOP)

## Features
1. Create a support ticket.
2. View all tickets.
3. Search tickets using Ticket ID.
4. Update ticket details.
5. Update ticket status.
6. Validate ticket category and priority.
7. Prevent empty ticket details.
8. Track ticket status: Open, In Progress, and Resolved.

## Project Files
- Main.java – Main menu and user interaction.
- Ticket.java – Ticket details and operations.
- TicketManager.java – Ticket management.
- User.java – User details.

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the Java files:

   `javac *.java`

4. Run the application:

   `java Main`

## Project Level
Beginner Java Project
